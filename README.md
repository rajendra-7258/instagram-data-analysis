# Instagram Data Analysis

Analysis of Instagram post and engagement data to uncover optimal posting times, high-performing content types, and follower growth signals. Includes engagement metric computation, hashtag/content trend analysis, and a data-driven content calendar with strategies to boost engagement.

## 📌 Goal

Analyze Instagram posts/engagement to identify best posting times, content types with high engagement, and follower growth signals.

## 📊 Dataset

Source: [Instagram Dataset on Kaggle](https://www.kaggle.com/datasets/bhanupratapbiswas/instgram)

## ✅ Requirements Covered

- **Data Parsing**: Parse post dates/times and compute engagement metrics (likes/comments per follower)
- **Trend Analysis**:
  - Posting schedule patterns
  - Hashtag usage
  - Content type performance
- **Strategy**: Recommended optimal content calendar and 5 strategies to increase engagement for Alfido Tech

## 📂 Deliverables

1. **Notebook** — contains analysis and visuals
2. **One-Page Strategy Document** — recommended posting plan

## 🛠️ Tech Stack

- Python
- Pandas / NumPy
- Matplotlib / Seaborn

## 🚀 How to Run

1. Clone the repo
   ```bash
   git clone <repo-url>
   cd instagram-data-analysis
   ```
2. Install dependencies
   ```bash
   pip install -r requirements.txt
   ```
3. Open the notebook
   ```bash
   jupyter notebook instagram_analysis.ipynb
   ```
